# Anchal Thool — Portfolio

A cinematic portfolio combining British art, editorial design, and software engineering.

## Local development

```bash
npm install
npm run dev
```

## GitHub Pages

This repository automatically builds and deploys through `.github/workflows/deploy-pages.yml` whenever `main` changes. Keep the repository name `anchalthool.github.io` to publish at `https://anchalthool.github.io`.

In **Settings → Pages**, set **Source** to **GitHub Actions**.

Artwork credits are available inside the site under **Artwork & colophon**.
